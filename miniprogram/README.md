# 西域果脯 · 微信小程序

> 一口西域，一份实在 — 敢给你看产地底牌的新疆干果品牌

## 项目结构

```
miniprogram/
├── app.js                          # 应用入口，云开发初始化
├── app.json                        # 页面路由 + Tab Bar 配置
├── app.wxss                        # 全局样式 + 品牌色板
├── project.config.json             # 小程序项目配置
├── utils/
│   ├── db.js                       # 云数据库操作封装
│   └── util.js                     # 通用工具函数
├── pages/
│   ├── index/                      # 🏠 首页：Banner、系列入口、商品推荐
│   ├── category/                   # 📦 分类：左侧分类 + 右侧商品网格
│   ├── product/detail/             # 🛍️ 商品详情：轮播图、6星评分、价格透明
│   ├── cart/                       # 🛒 购物车：加减、全选、结算
│   ├── order/
│   │   ├── confirm/                # ✅ 订单确认：选地址、提交
│   │   ├── list/                   # 📋 订单列表：待付款/待发货/待收货
│   │   └── detail/                 # 📄 订单详情
│   ├── address/
│   │   ├── list/                   # 📍 地址列表
│   │   └── edit/                   # ✏️ 编辑地址
│   ├── user/                       # 👤 我的：订单入口、地址、客服
│   └── story/                      # 📖 品牌故事：三大支柱/6星标准/产地/价格
└── cloudfunctions/
    ├── submitOrder/                 # 提交订单 + 微信支付
    ├── payCallback/                 # 支付结果回调
    ├── getProducts/                 # 商品列表（含种子数据）
    └── getOrders/                   # 订单列表
```

## 快速开始

### 第 1 步：注册小程序

1. 前往 [微信公众平台](https://mp.weixin.qq.com/) 注册小程序账号
2. 完成企业认证（300元/年）
3. 在「开发 → 开发管理 → 开发设置」中获取 **AppID**

### 第 2 步：开通云开发

1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 用你的 AppID 创建项目，选择 `miniprogram/` 作为项目目录
3. 在开发者工具中点击「云开发」图标
4. 开通云开发 → 创建环境（选「按量付费」，免费额度够起步）
5. 记录你的**环境 ID**

### 第 3 步：配置项目

1. 将 `project.config.json` 中的 `"appid": "your-appid-here"` 替换为你的 AppID
2. 将 `app.js` 中的 `env: 'your-env-id'` 替换为你的云开发环境 ID

### 第 4 步：创建数据库集合

在云开发控制台 → 数据库中创建以下集合：

| 集合名 | 说明 | 权限 |
|--------|------|------|
| `categories` | 商品分类 | 所有用户可读，仅创建者可写 |
| `products` | 商品数据 | 所有用户可读，仅创建者可写 |
| `carts` | 购物车 | 仅创建者可读写 |
| `orders` | 订单 | 仅创建者可读写 |
| `addresses` | 收货地址 | 仅创建者可读写 |
| `giftSets` | 套餐/礼盒 | 所有用户可读，仅创建者可写 |

> 每个集合的设置 → 权限设置 → 按需选择「仅创建者可读写」或「所有用户可读，仅创建者可写」

### 第 5 步：导入种子数据

在云开发控制台 → 数据库中，逐条导入或批量导入：

1. **categories** 集合：导入 3 条分类（尝鲜精选、西域珍品、口碑好物）
2. **products** 集合：导入 13 条商品数据
3. **giftSets** 集合：导入 3 条套餐数据

种子数据参考 `cloudfunctions/getProducts/index.js` 文件底部。

### 第 6 步：上传图片

1. 在云开发控制台 → 存储 → 上传文件
2. 将 `../image2/` 目录下的所有 PNG 图片上传
3. 更新 `products` 集合中每件商品的 `images` 字段为实际的云存储 URL

### 第 7 步：上传并部署云函数

在微信开发者工具中：
1. 右键点击 `cloudfunctions/` 下的每个云函数文件夹
2. 选择「上传并部署：云端安装依赖」

### 第 8 步：配置 Tab Bar 图标

替换 `miniprogram/images/` 目录下的图标文件：
- `tab-home.png` / `tab-home-active.png`（首页图标，81x81 像素）
- `tab-category.png` / `tab-category-active.png`（分类图标）
- `tab-cart.png` / `tab-cart-active.png`（购物车图标）
- `tab-user.png` / `tab-user-active.png`（我的图标）

### 第 9 步：预览和提交审核

1. 在开发者工具中点击「预览」，扫码在手机上测试
2. 确认功能无误后，点击「上传」
3. 在微信公众平台 → 版本管理 → 提交审核
4. 审核通过（1-7 个工作日）后发布

## 微信支付配置（Phase 1 后期）

1. 在微信公众平台 → 功能 → 微信支付 申请开通
2. 关联商户号（MCHID）
3. 在云开发控制台 → 云函数 → `submitOrder` 中配置支付参数
4. 将 `payCallback` 设置为支付结果通知云函数

> **提示**：在支付商户号配置完成之前，`submitOrder` 云函数会创建订单但不发起支付，不影响前端流程调试。
